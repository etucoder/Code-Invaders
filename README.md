# Code Invaders
A Space-Invaders Themed Game where you defend your code files from different errors and upgrade your ship to survive...

### Why I built this
I built this project because I wanted to make a fun game about programming and bugs. I also wanted to try a multiplayer game for the first time, and this was my first time commiting to a project for so long.

## My journey
I started out this project planning to build a basic space invaders clone. Since I had nothing better to do over the summer, and I enjoy programming, I added multiplayer, 4 different weapon types, 12+ enemy types, and other features , since I was commiting to this project for so long.
# How to open and play
Option 1 : Open the Itch.io page, download the .zip, unpack it, and run main1.exe


# How to play
 ---> Control your ship with the arrow keys / WASD
 ---> Press spacebar to shoot a laser
 ---> Try to hit the enemies falling from the sky
 ---> Prevent the enemies from hitting your files
 ---> If a file takes enough damage , it will get deleted. Your game will end.
 ---> If your ship gets hit, you lose a life
 ---> If you lose all 3 lives, the game will end
 ---> After every level, get 2-3 choices of upgrade cards to pick from to increase your stats

# Stategies
Focus on rows, not columns.
If a file has low health, protect it
If a file is about to take a final hit before it dies, and you have 3 lives, jump in front of it to block the hit, preventing the game from ending
